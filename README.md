# C++ Modules - 42 School

## 🎓 À propos

Ce projet fait partie du cursus de l'**école 42**.

Les **modules C++** (cpp00 à cpp09) constituent une série d'exercices conçus pour apprendre le C++ en venant du C. Chaque module introduit de nouveaux concepts du langage.

---

## 📚 Modules

| Module | Thème | Concepts |
|--------|-------|----------|
| **cpp00** | Bases | Classes, objets, attributs, méthodes |
| **cpp01** | Mémoire | Allocation, références, pointeurs |
| **cpp02** | Polymorphisme ad-hoc | Surcharge d'opérateurs, forme canonique |
| **cpp03** | Héritage | Classes dérivées, héritage simple |
| **cpp04** | Polymorphisme | Classes abstraites, interfaces, virtuel |
| **cpp05** | Exceptions | try/catch/throw, gestion d'erreurs |
| **cpp06** | Casts | static_cast, dynamic_cast, reinterpret_cast |
| **cpp07** | Templates | Fonctions et classes génériques |
| **cpp08** | STL | Containers, iterators, algorithmes |
| **cpp09** | STL avancé | Containers associatifs, complexité |

---

## ⚙️ Contraintes

- Standard : **C++98** (pas de fonctionnalités modernes)
- Compilation : `g++ -Wall -Wextra -Werror -std=c++98`
- Forme canonique obligatoire (constructeurs, destructeur, opérateur=)
- Pas de fuites mémoire

---

## 🚀 Compilation

Chaque exercice contient un `Makefile` :

```bash
cd cppXX/exYY
make        # Compile
./program   # Exécute
make clean  # Nettoie
```
